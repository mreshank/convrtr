# Strict Policy: Zero Emojis in Product

Under NO circumstances should emojis ever be used in this product.

## Rules:
1. **Never use emojis in UI, product copy, or labels**: No emojis on buttons, chips, tabs, headers, notifications, tooltips, dialogs, badges, or menus.
2. **Never use emojis in code or logs**: No emojis in `console.log`, build scripts, test scripts, comments, or terminal outputs.
3. **Never use emojis in documentation or store listings**: No emojis in READMEs, release notes, Chrome Web Store listings, or guides.
4. **Never use emojis in commit messages or PR descriptions**: Use conventional commit titles (`feat:`, `fix:`, `refactor:`) without emojis.
5. **Design Aesthetic**: convrtr adheres strictly to a high-contrast brutalist, utilitarian, Dieter Rams-inspired typography and instrument aesthetic. Use uppercase monospace text, geometric arrows (`↗`, `➔`, `▲`, `▼`), or minimalist SVGs when visual indicators are necessary.
